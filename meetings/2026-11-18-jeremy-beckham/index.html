Building AI Agents in Microsoft Foundry: From First Prompt to Production

Jeremy Beckham

Wednesday, November 18, 2026 · 5:15 PM

AI agents are everywhere in the headlines, but what does it actually take to build one that works? In this session, Jeremy walks through the full journey of developing an agent in Microsoft Foundry, starting with the fundamentals of how LLMs and agents work and ending with the tracing, evaluation, and guardrails that make agents trustworthy in production. Through live demos built around a single working example, attendees will see how to create an agent in the Foundry portal, extend it in code with Microsoft Agent Framework, and monitor its behavior once it’s running. Whether you’ve never called an LLM API or you’re already shipping AI features, you’ll leave with a clear map of the Foundry platform and practical lessons from real-world agent development.

About Jeremy Beckham

Jeremy is an AI Solutions Architect at EisnerAmper, where he builds AI systems for the firm’s Eisner AI practice. He specializes in Microsoft Foundry, including RAG pipelines, document processing, and production-ready agents with strong observability and evaluation. He is also the CTO of mArshlIne AI, a central Louisiana based company that builds AI based products for multiple industries.
