About

What is BRSSUG?

The Baton Rouge SQL Server User Group has been connecting local technology professionals for years. We're a free, community-run group focused on SQL Server, the Azure data platform, Power BI, and related Microsoft data tools.

Meetings feature presentations from local experts and Microsoft MVPs, followed by open discussion and networking. Whether you're a seasoned DBA, a BI developer, or just getting started — you're welcome here.
