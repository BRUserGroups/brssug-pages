About

What is BRSSUG?

The Baton Rouge SQL Server & .NET User Group has been connecting local technology professionals for years. We're a free, community-run group focused on SQL Server, Azure data platform, Power BI, .NET, and related Microsoft technologies.

Meetings feature presentations from local experts and Microsoft MVPs, followed by open discussion and networking. Whether you're a seasoned DBA, a .NET developer, or just getting started — you're welcome here.
