Baton Rouge SQL Server User Group

A free, no-registration-required user group for professionals and students in the broad field of Microsoft SQL Server and .NET — meeting monthly in Baton Rouge since the early 2000s.

Who we are

The Baton Rouge SQL Server User Group (BRSSUG.org) is a free, no-registration-required user group for professionals and students in the broad field of Microsoft SQL Server. The group aims to provide a platform for growing your skillset in Information Technology and your professional network, and works closely with local and regional partners to make our monthly meetings interesting and informative.

We meet every second Wednesday of the month on a wide range of topics including Business Intelligence, Disaster Recovery, SQL Server performance and monitoring, and SQL Server development.

The goal is to help the Baton Rouge area SQL community become more involved, educated, and capable technology professionals.

Partner groups

Meetings are held monthly in conjunction with our partner user groups:

  • Baton Rouge Analytics & Intelligence Network — gobrain.org
  • Baton Rouge .NET User Group — BRDNUG.org

Not-for-profit corporation

BRSSUG operates under Baton Rouge User Groups, a Louisiana not-for-profit corporation (501c6) formed to support all user groups and user group events with financial logistics. Baton Rouge User Groups has supported the SQL and .NET user groups as well as Day of Data events. Our EIN and a W-9 are available upon request.

Day of Data Baton Rouge

BRSSUG hosts an annual full-day data conference — free sessions, great speakers, and the Baton Rouge data community all in one place. For more information on speaking, volunteering, or attending, visit dayofdatabr.org.
